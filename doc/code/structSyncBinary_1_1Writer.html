Remarks

The ISyncManager implementation for writing SyncLib's compact, high-performance binary data format (see SyncBinary for details and guidelines). Please call WriteI or Write if you just want to serialize something, or NewWriter to create one of these.

This is a struct rather than a class for performance reasons. Don't try to use a default(Writer); it'll just throw NullReferenceException.
